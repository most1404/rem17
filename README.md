# یادآور شمسی — نسخه اصلاحیه UX

پروژه Android/Kotlin با Gradle Wrapper و GitHub Actions.

## ساخت APK در GitHub
1. محتویات این پوشه را در ریشه مخزن GitHub بارگذاری کنید.
2. به تب Actions بروید و workflow با نام Build APK را اجرا کنید.
3. پس از موفقیت، artifact خروجی را دانلود کنید.

## تغییرات اعمال‌شده در این اصلاحیه
- پالت رنگی ملایم‌تر و پس‌زمینه برنامه با ته‌رنگ تم انتخاب‌شده.
- نمایش متمایز روز جاری در تقویم شمسی، حتی وقتی روز جاری انتخاب نشده است.
- حذف تب «ویجت» از نوار پایین برنامه.
- دکمه + صفحه اصلی مستقیماً فرم یادآور جدید را باز می‌کند.
- افزودن دکمه‌های «بازگرداندن» و «ویرایش» برای یادآورهای انجام‌شده.
- پشتیبان JSON داخلی در فضای خصوصی برنامه پس از تغییرات دیتابیس.
- چیدمان تاریخ و ساعت در صفحه ثبت یادآور به‌صورت دو ستونه.

## محدودیت‌های بررسی
در این محیط Android SDK/Gradle build قابل اجرا نبود؛ بنابراین APK کامپایل و روی دستگاه آزمایش نشده است. پشتیبان داخلی در فضای خصوصی برنامه قرار دارد و با حذف برنامه پاک می‌شود؛ برای نسخه خارج از برنامه، همچنان از قابلیت انتخاب فایل/Google Drive در تنظیمات استفاده کنید. هشدار قبل از موعد (۱۵ دقیقه/۳۰ دقیقه/۱ ساعت/زمان دلخواه) در این نسخه پیاده‌سازی نشده، چون برای پشتیبانی واقعی نیازمند تغییر مدل ذخیره‌سازی و زمان‌بندی مستقل آلارم است؛ اضافه‌کردن صرفاً کنترل ظاهری بدون اتصال به زمان‌بندی می‌توانست باعث هشدار اشتباه شود.
